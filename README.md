# 🧠 Deep Learning Laboratory

A collection of **Deep Learning Laboratory Assignments** implemented using Python, covering fundamental neural network concepts, deep learning architectures, computer vision, natural language processing, and model optimization.

---

## 📚 Laboratory Assignments

| Sr. No. | Experiment / Assignment | Overview |
|:---:|---|---|
| 01 | **Implement a Perceptron from Scratch** | Implement a single-layer perceptron using NumPy, train it on linearly separable data, and visualize its decision boundary. |
| 02 | **Feedforward Neural Network** | Build and train a Multi-Layer Perceptron (MLP) using a deep learning framework and evaluate its performance. |
| 03 | **Regularization Techniques** | Explore L2 regularization and Dropout to understand their impact on model generalization and overfitting. |
| 04 | **Activation Functions** | Compare Sigmoid, Tanh, and ReLU based on training performance, accuracy, and gradient behavior. |
| 05 | **Convolutional Neural Network** | Develop a CNN for image classification and compare its performance with a traditional MLP. |
| 06 | **RNN / LSTM for Text Classification** | Implement an LSTM-based model for binary sentiment classification using the IMDB dataset. |
| 07 | **Transfer Learning with Pretrained CNNs** | Fine-tune pretrained ResNet50 and VGG16 architectures for image classification. |
| 08 | **Hyperparameter Tuning and Model Comparison** | Experiment with different hyperparameters and compare model configurations using TensorBoard. |

## 🎯 Learning Objectives

Through these laboratory assignments, the following concepts and practical skills are explored:

- Understanding the fundamentals of artificial neural networks and perceptrons.
- Building, training, and evaluating feedforward neural networks.
- Applying regularization techniques to improve model generalization.
- Understanding activation functions and gradient-related problems.
- Developing CNN architectures for image classification.
- Implementing recurrent neural networks for text classification.
- Applying transfer learning using pretrained deep learning models.
- Performing hyperparameter tuning and comparing model performance.
- Visualizing training metrics, accuracy, and loss using appropriate tools.

## 📁 Repository Contents
